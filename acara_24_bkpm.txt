d. Dasar Teori  
Fetch API sebagai Antarmuka Komunikasi HTTP 
Fetch API menyediakan antarmuka JavaScript modern untuk melakukan 
permintaan HTTP dan memproses response, menggantikan XMLHttpRequest yang 
berbasis callback. Berdasarkan dokumentasi resmi MDN, pemanggilan fetch() 
mengembalikan sebuah Promise yang selesai (fulfilled) begitu server merespons 
dengan header, sehingga proses pembacaan body response (misalnya melalui 
method .json()) dilakukan pada tahap terpisah. 
 
Asynchronous Request dengan Async/Await 
Sintaks async/await memungkinkan kode asynchronous ditulis secara 
berurutan (sequential) sehingga lebih mudah dibaca dibandingkan rangkaian 
.then(). Penanganan kegagalan permintaan (misalnya jaringan terputus) dilakukan 
melalui blok try-catch di sekeliling pemanggilan await fetch(...). 
 
Cross-Origin Resource Sharing (CORS) 
CORS adalah mekanisme keamanan berbasis header HTTP yang mengatur 
apakah sebuah halaman web pada satu origin (domain, skema, atau port) 
diperbolehkan mengakses resource dari origin lain. Berdasarkan dokumentasi 
resmi MDN, browser akan menolak response dari server lain kecuali server tersebut 
secara eksplisit mengirimkan header seperti Access-Control-Allow-Origin yang 
mengizinkan permintaan tersebut.

f. Prosedur Kerja  
View pertama dibangun pada public/views/, sementara header CORS 
ditambahkan satu kali pada Front Controller (public/index.php) agar berlaku untuk 
seluruh resource yang melewati Router. 
 
Langkah 1 — Mengaktifkan Header CORS pada Front Controller 
Tambahkan header CORS pada awal public/index.php, sebelum Router dijalankan, 
sehingga berlaku otomatis untuk seluruh resource (mahasiswa, login, register, dan 
resource baru di acara berikutnya). 
public/index.php (diperbarui) 
<?php 
header('Access-Control-Allow-Origin: *'); 
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS'); 
header('Access-Control-Allow-Headers: Content-Type, Authorization'); 
  
require_once __DIR__ . '/../app/core/autoload.php'; 
(new Router())->dispatch();

Langkah 3 — Menulis Kode Fetch untuk Menampilkan Data 
public/views/app.js 
const BASE_URL = 'http://localhost/sistem-informasi-akademik/public'; 
  
async function muatDataMahasiswa() { 
    try { 
        const response = await fetch(`${BASE_URL}/mahasiswa`); 
        const hasil = await response.json(); 
        const tbody = document.querySelector('#tabel-mahasiswa tbody'); 
        tbody.innerHTML = ''; 
        hasil.data.forEach((mhs) => { 
            tbody.innerHTML += 
`<tr><td>${mhs.nim}</td><td>${mhs.nama}</td><td>${mhs.prodi}</td></tr>`; 
        }); 
    } catch (error) { 
        console.error('Gagal memuat data:', error); 
    } 
} 
  
document.addEventListener('DOMContentLoaded', muatDataMahasiswa);
