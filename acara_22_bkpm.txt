d. Dasar Teori  
Standar OpenAPI Specification 
OpenAPI Specification (dahulu dikenal sebagai Swagger Specification) 
merupakan format standar industri untuk mendeskripsikan REST API dalam 
dokumen YAML atau JSON yang dapat dibaca baik oleh manusia maupun mesin. 
Dibandingkan dokumentasi Markdown manual yang dibuat pada acara 21, OpenAPI 
menawarkan keunggulan berupa struktur yang baku, dapat divalidasi secara 
otomatis, serta dapat digunakan untuk men-generate dokumentasi interaktif 
maupun kode klien secara otomatis. Sejak tahun 2015, spesifikasi Swagger 2.0 
didonasikan kepada OpenAPI Initiative di bawah Linux Foundation, dan versi 
terbaru (OpenAPI 3.x) membawa berbagai penyempurnaan dibandingkan Swagger 
2.0. 
 
Swagger Editor dan Swagger UI sebagai Alat Visualisasi 
Swagger Editor adalah alat berbasis web yang memungkinkan penulisan 
dokumen OpenAPI dengan pratinjau (preview) dokumentasi secara langsung, 
sementara Swagger UI menghasilkan halaman dokumentasi interaktif yang 
memungkinkan pengguna mencoba langsung (try-it-out) setiap endpoint dari 
tampilan dokumentasi tanpa berpindah ke Postman.

f. Prosedur Kerja  
Dokumentasi Markdown acara 21 dikonversi menjadi OpenAPI 3.0, dengan 
path yang mengikuti resource pada peta Router (bukan lagi nama berkas .php). 
 
Langkah 1 — Membuat File openapi.yaml 
docs/openapi.yaml (kerangka awal) 
openapi: 3.0.0 
info: 
  title: API Sistem Informasi Akademik (MVC) 
  version: 1.0.0 
servers: 
  - url: http://localhost/sistem-informasi-akademik/public 
paths: {} 
 
Langkah 2 — Mendefinisikan Path /login 
paths: 
  /login: 
    post: 
      summary: Autentikasi pengguna (AuthController::login) 
      requestBody: 
        content: 
          application/json: 
            schema: 
              type: object 
              properties: 
                username: { type: string } 
                password: { type: string } 
      responses: 
        '200': { description: Login berhasil } 
        '401': { description: Kredensial tidak valid } 
 
Langkah 3 — Mendefinisikan Path /mahasiswa 
  /mahasiswa: 
    get: 
      summary: Mengambil data mahasiswa (MahasiswaController::index) 
      parameters: 
        - name: id 
          in: query 
          schema: { type: integer } 
      responses: 
        '200': { description: Data berhasil diambil } 
    post: 
      summary: Menambahkan data mahasiswa (MahasiswaController::store) 
      security: [ { bearerAuth: [] } ] 
      responses: 
        '201': { description: Data berhasil ditambahkan } 
 
Langkah 4 — Memvisualisasikan Dokumentasi 
1. Buka https://editor.swagger.io pada browser.
