d. Dasar Teori  
Konsep Pengujian Perangkat Lunak dan Manual Testing 
Pengujian (testing) adalah proses eksekusi program dengan tujuan 
menemukan kesalahan (bug) serta memastikan perangkat lunak berjalan sesuai 
spesifikasi yang telah ditentukan. Manual testing dilakukan oleh penguji secara 
langsung tanpa bantuan skrip otomatis, sehingga sangat sesuai diterapkan pada 
skala proyek workshop menggunakan alat bantu seperti Postman. 
 
Blackbox Testing 
Blackbox testing merupakan metode pengujian yang berfokus pada 
fungsionalitas sistem tanpa memerlukan pengetahuan mengenai struktur kode 
internal. Penguji hanya perlu memberikan data masukan (input) dan mengamati 
apakah keluaran (output) sesuai dengan hasil yang diharapkan, menjadikan 
metode ini populer digunakan untuk menguji aplikasi maupun API berbasis web 
pada berbagai penelitian sistem informasi. 
 
Teknik Equivalence Partitioning 
Equivalence Partitioning adalah teknik pada blackbox testing yang membagi 
domain data masukan ke dalam beberapa partisi/kelas ekuivalen, yaitu partisi valid 
dan partisi tidak valid, sehingga pengujian cukup dilakukan pada satu perwakilan 
data dari tiap partisi tanpa harus menguji seluruh kemungkinan kombinasi data, 
sehingga proses pengujian menjadi lebih efisien namun tetap representatif. 
 
Penyusunan Test Case 
Test case yang baik umumnya memuat kolom: ID Test Case, Skenario Pengujian, 
Data Uji, Hasil yang Diharapkan, Hasil Aktual, dan Status (Pass/Fail). Struktur ini
