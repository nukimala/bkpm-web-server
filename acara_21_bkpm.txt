d. Dasar Teori 
Pentingnya Dokumentasi API 
Dokumentasi yang tidak jelas dan sering usang merupakan salah satu keluhan 
terbesar developer ketika mengintegrasikan API pihak lain. Dokumentasi API yang 
baik mempercepat proses integrasi, mengurangi kebutuhan komunikasi bolak-balik 
antara tim backend dan frontend, serta menjadi rujukan resmi ketika terjadi 
perbedaan pemahaman mengenai perilaku suatu endpoint. 
 
Elemen-Elemen Dokumentasi Endpoint yang Baik 
• Method HTTP dan URL endpoint 
• Header yang dibutuhkan (misalnya Content-Type, Authorization) 
• Struktur body request beserta tipe data tiap field 
• Contoh response untuk skenario sukses dan gagal, lengkap dengan kode status 
• Keterangan autentikasi yang dibutuhkan (publik atau terproteksi) 
 
Dokumentasi API melalui Postman 
Selain sebagai alat pengujian, Postman menyediakan fitur untuk menuliskan 
deskripsi pada tiap request dan Collection, serta dapat menghasilkan tampilan 
dokumentasi (View Documentation) secara otomatis berdasarkan request dan 
contoh response yang telah disimpan, sehingga proses pembuatan dokumentasi 
dapat menyatu dengan proses pengujian yang sudah dilakukan sejak acara 19.

Controller: AuthController::login() 
  
**Headers:** Content-Type: application/json 
  
**Request Body:** 
