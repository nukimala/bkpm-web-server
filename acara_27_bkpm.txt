d. Dasar Teori
FormData untuk Pengiriman Data Multipart
Antarmuka FormData memungkinkan penyusunan sekumpulan pasangan key-value, termasuk berkas, untuk dikirim menggunakan fetch() dengan format yang sama seperti pengiriman form HTML biasa (multipart/form-data). Berdasarkan dokumentasi resmi MDN, ketika mengirim FormData melalui fetch(), header Content-Type sebaiknya tidak diatur secara manual, karena browser perlu menyertakan boundary delimiter secara otomatis untuk memisahkan setiap field data di dalam body request; mengatur header ini secara manual justru dapat menyebabkan proses upload berkas gagal diproses oleh server.

Sinkronisasi Operasi CRUD pada Frontend dengan Endpoint API
Pada frontend berbasis JavaScript murni, operasi Update dan Delete umumnya dilakukan dengan mengirim method PUT/DELETE melalui opsi method pada fetch(), disertai penyertaan id data pada query string dan token autentikasi pada header Authorization, sebagaimana pola yang telah dirancang sejak acara 20.

Form ini menggunakan FormData sebagaimana diperkenalkan pada acara 26, kini dilengkapi header Authorization.

Langkah 2 — Membuat View Edit Data (form_edit.html)
async function muatDataUntukEdit(id) {
    const res = await fetch(`${BASE_URL}/mahasiswa?id=${id}`);
    const hasil = await res.json();
    nim.value = hasil.data.nim;
    nama.value = hasil.data.nama;
    prodi.value = hasil.data.prodi;
}
async function simpanPerubahan(id) {
    const formData = new FormData();
    formData.append('nim', nim.value);
    formData.append('nama', nama.value);
    formData.append('prodi', prodi.value);
    await fetch(`${BASE_URL}/mahasiswa?id=${id}`, {
        method: 'PUT',
        headers: { 'Authorization': `Bearer ${localStorage.getItem('token')}` },
        body: formData,
    });
}

Langkah 3 — Menambahkan Tombol Hapus pada Tabel Dashboard
async function hapusData(id) {
    if (!confirm('Hapus data ini?')) return;
    await fetch(`${BASE_URL}/mahasiswa?id=${id}`, {
